## Ejercicio 9

**1. ¿Qué retorna el bloque de código?**
Retorna `{1, 3, 4}`, porque primero se agrega el `4` al conjunto `{1, 2, 3}` y luego se elimina el `2`.

**2. ¿Cuántas funciones se declararon?**
Se declararon **2 funciones**: `agregar_elemento()` y `eliminar_elemento()`.

**3. ¿Qué imprime en consola?**
No imprime nada, ya que el código no contiene ninguna instrucción `print()`.

## Ejercicio 10

**a. Resultado:**
`[12, 15, 18]`

**b. Paso a paso:**
`map()` aplica la función `lambda` a los elementos de las tres listas simultáneamente. La `lambda` suma los valores de cada posición:

* `1 + 4 + 7 = 12`
* `2 + 5 + 8 = 15`
* `3 + 6 + 9 = 18`

Por último, `list(resultado)` convierte el objeto `map` en una lista para poder mostrar los resultados.
